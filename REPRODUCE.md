## Dates

Each commit is dated at noon (Europe/Brussels) on the day the change took effect. The other dates, enacted and published, are trailers.

When a law gives no date of its own, the default rule applies: Loi du 31 mai 1961, art. 4, al. 2: les lois "sont obligatoires dans tout le royaume le dixième jour après celui de leur publication, à moins que la loi n'ait fixé un autre délai". Every date here is the in-force day Justel prints in its note on the change, which applies that rule or the law's own clause. https://www.ejustice.just.fgov.be/eli/loi/1961/05/31/1961053107/justel

## How the history is built

`tools/build.py` turns the corpus into this history in one pass: one commit per law, on the day it took effect. The same corpus always gives the same commit hashes. `tools/check_repo.py` reads every version back from git and compares it with the corpus. `tools/on.py` shows the law as it stood on any date. The corpus format is described in `tools/SCHEMA.md`.

## Decisions made by hand

- Constitution: text from legalize-be (78 files for NUMAC 1994021048, one per Justel archived version, pinned commit) and, for the revisions after legalize-be's last file (L 2025-06-12/07 and L 2026-07-15/04), the archived Justel page of 24 August 2026 (Internet Archive capture 20260824161257).
- Constitution: legalize-be's files after the first hold only the articles touched so far, and an article's new wording often appears several archived versions after the version that made it; so each article's successive wordings are taken in file order and each is dated by the Justel notes it gained (their in-force day), never by legalize-be's commit date (which is often the publication date plus ten days).
- Constitution: the first version (27 February 1994, Justel's in-force date for the coordinated text) is legalize-be's first file. Articles inserted later appear in that file with their later wording; each is left out until the in-force day of its "Inséré par" note (7bis, 11bis, 14bis, 22bis, 22ter, 39bis, 39ter, 118bis, 135bis, 168bis).
- Constitution: 3 wordings differed from the next only in Justel's typesetting (older versions mark changed words with parentheses, later ones with brackets; case, accents and final stops tidied later); each paragraph takes Justel's latest rendering of the same words.
- Constitution: Justel's inline notes and change markers ([¹ ]¹, older bare brackets) are removed from the text; a provision that Justel shows only as a repeal note reads "(Abrogé)". The anchors M, M1, M2 (structure) and N1, N2 (the 1994 correspondence tables, which Justel does not reproduce) are not provisions.
- Constitution: law labels are Justel's citations, "L <date of the act>/<Justel serial>"; every one here is a revision of the Constitution, and the link opens its Justel record. Their Moniteur belge publication dates are not in the source data, so "published" is left empty.
- Constitution: compared with 70 archived Justel pages (2009-2026): 37 match provision for provision on their capture day, ignoring typesetting; see verification/constitution.json.
- Constitution: 1 changes have no new dated note; they are committed as unexplained (publisher), dated by the Justel version (legalize-be Source-Id date) or capture that first shows them: art-140 (2008-12-29).
- Code pénal: text from legalize-be (166 files for NUMAC 1867060850, one per Justel archived version, from 5 April 1990, the start of Justel's archive) and, after legalize-be's last file (Justel update of 18 February 2026), the archived Justel page of 3 May 2026 (Internet Archive capture 20260503012006). The first version is the oldest text available (5 April 1990), credited to the publisher, not the Code as enacted in 1867.
- Code pénal: each article's successive wordings are dated by the Justel notes they gained, as for the Constitution; legalize-be's commit dates are not used.
- Code pénal: the new Code pénal (lois du 29 février 2024, livres I et II) replaces the 1867 Code. Its in-force day was first set at two years after publication (8 April 2026); Justel's note on art. 38 of the livre I law records its postponement to 1 September 2026 by L 2026-03-30/01, art. 252, and Justel's page of 3 May 2026 still shows the 1867 Code in force. No source used here gives the clause for livre II, so the replacement is not committed: the 1867 Code ends with its last sourced version. The new Code is not built: legalize-be's files for the two laws mix the laws' own articles with the Code's, under the same numbers.
- Code pénal: Justel added the euro conversion (L 2000-06-26/42, in force 1 January 2002) to many articles only in 2010; those articles carry euros from 1 January 2002 here, so Justel's pages of 2009 and early 2010 differ from this history in about 200 articles, all but 5 of them by francs and euros only.
- Code pénal: words the Constitutional Court annulled (Justel prints them in italics with a note naming the ruling) are removed from the day the ruling was published in the Moniteur belge, credited to the ruling (kind "court"), e.g. arrêt n° 148/2017.
