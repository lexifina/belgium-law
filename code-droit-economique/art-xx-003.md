Sans préjudice des effets que le Code judiciaire attribue aux significations, les délais prennent cours lorsque le présent livre impose l'insertion de données ou de pièces dans le registre, à partir du jour suivant celui de l'insertion.
Les articles 50, alinéa 2, 55 et 56 du Code judiciaire ne sont pas applicables aux actions et aux significations prévues par le présent livre.
