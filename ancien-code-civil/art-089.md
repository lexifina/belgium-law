Le quartier-maître dans chaque corps d'un ou plusieurs bataillons ou escadrons, et le capitaine commandant dans les autres corps, rempliront les fonctions d'officiers de l'état civil: ces mêmes fonctions seront remplies, pour les officiers sans troupes et pour les employés de l'armée, par l'officier d'administration dans les bataillons, officier commandant de compagnie ou d'unité indépendante dans les compagnies ou unités indépendantes..
