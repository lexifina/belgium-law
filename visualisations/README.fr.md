# Le droit belge en 20 graphiques

[Nederlands](README.md) · [English](README.en.md)

Des graphiques sur le droit de tous les pays, tirés de l'ensemble de global-law  [global-law visualisations/](https://github.com/lexifina/global-law/tree/main/visualisations). Ici figurent uniquement les graphiques sur la Belgique.

Vingt graphiques sur le droit belge, tirés uniquement des données de ce dépôt  la Constitution et 23 codes et lois avec chacune de leurs versions issues de Justel et les actes qui les ont modifiés, 753 actes de 2025 des huit législateurs belges, les lois fédérales de 2026, le nouveau Code pénal, et des décisions de la Cour de cassation, du Conseil d'État et de la Cour constitutionnelle.

Ouvrez [`belgisch-recht-in-20-grafieken.html`](belgisch-recht-in-20-grafieken.html) dans un navigateur. La page est un seul fichier qui contient toutes ses données  elle ne charge du web que les bibliothèques d3 et topojson, la carte du monde du graphique 5 et ses polices. Les boutons en haut à droite choisissent la langue (néerlandais, français ou anglais) et l'affichage (clair ou sombre). Chaque graphique indique sa source dans le dépôt, le nombre d'enregistrements et ses limites, et comporte en dessous un tableau de tous les chiffres. Survolez un élément pour les valeurs exactes.

Les graphiques sont descriptifs  ils montrent ce que les sources enregistrent, pas pourquoi.

## Limites

- **Les actes de 2025 sont une sélection.** Le dépôt contient les actes des premières pages des listes de Justel, la plupart signés en octobre–décembre 2025  les parts des graphiques 1 à 6 sont celles de cette sélection, pas d'une année complète.
- **Les codes commencent dans l'archive de Justel.** La plupart des codes et lois commencent au plus ancien texte que conserve Justel (le Code judiciaire en 1985, le Code pénal en 1990, l'ancien Code civil et le Code d'instruction criminelle en 2009), pas tels qu'ils ont été adoptés  les premières années comptent donc moins de codes (graphiques 8 à 14).
- **Les catégories viennent des intitulés et des textes.** Le type d'acte (graphiques 1 et 7), l'assentiment aux traités (5), la transposition des directives (6), la procédure des lois fédérales (7) et les niveaux de peine (16) sont lus dans les intitulés et les textes, selon les règles de `src/prep.py`.
- **L'effet rétroactif** figure dans le dépôt au jour de la publication (graphique 10)  c'est ce jour qui compte dans les graphiques 9 et 14.
- **Une seule donnée vient d'en dehors du dépôt ** les mois des élections fédérales du graphique 8, comme repère.
- **La jurisprudence est une sélection** (graphiques 19 et 20)  surtout des métadonnées et le lien officiel, avec le texte pour une partie des décisions.
- **Les périodes incomplètes** (2025 et 2026 dans les codes, juin 1996 au Conseil d'État) sont dessinées plus claires.

## Reconstruire

```sh
python visualisations/src/make.py            # historique git + tableaux + textes -> src/.build/ -> belgisch-recht-in-20-grafieken.html
node visualisations/src/stills.cjs           # images de ces README (Playwright requis ; PLAYWRIGHT=<chemin> s'il n'est pas global)
```

`make.py` lit tout dans les objets git  il fonctionne donc aussi dans un clone sans blobs ou en `--no-checkout` (il récupère les blobs dont il a besoin en une requête par étape). Il lit `origin/main` (ou `HEAD`) par défaut  `--ref` choisit une autre branche ou un autre commit. Il n'écrit rien dans le dépôt, sauf la page et le dossier `src/.build/` (que git ignore).

| Fichier | Ce qu'il fait |
| --- | --- |
| `src/make.py` | extrait l'historique, les tableaux et les textes dans `src/.build/`, puis lance `prep.py` et `build.py` |
| `src/prep.py` | calcule chaque chiffre des 20 graphiques et le profil des données dans `src/.build/data.json` |
| `src/page.tpl.html` | la page  le texte en trois langues, les graphiques (d3), les tableaux |
| `src/build.py` | met `data.json` dans le gabarit et écrit la page |
| `src/stills.cjs` | dessine chaque graphique en png dans `stills/nl/`, `stills/fr/` et `stills/en/` |
