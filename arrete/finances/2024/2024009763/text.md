<a name="Art.1er"></a>Article <a href="#Art.2">1er</a>. A l'article 3 de l'arrêté royal du 5 octobre 2023 fixant les modalités spécifiques d'émission des loteries à billets, appelées " Winter Magic 2 euros ", " Winter Magic 5 euros " et " Winter Magic 10 euros ", loteries publiques organisées par la Loterie Nationale, les modifications suivantes sont apportées :
1° dans le paragraphe 1er, alinéa 2, le mot " cadeau " est remplacé par le mot " étoile " ;
2° dans le paragraphe 2, les mots " " feu d'artifice " " sont remplacés par les mots " " feu d'artifice composé d'étoiles " ".

<a name="Art.2" href="#Art.1er">Art.</a> <a href="#Art.3"> 2</a>. A l'article 7 du même arrêté, les modifications suivantes sont apportées :
1° dans le paragraphe 1er, alinéa 2, le mot " cadeau " est remplacé par le mot " étoile " ;
2° dans le paragraphe 2, les mots " " feu d'artifice " " sont remplacés par les mots " " feu d'artifice composé d'étoiles " ".

<a name="Art.3" href="#Art.2">Art.</a> <a href="#Art.4"> 3</a>. Le présent arrêté entre en vigueur le jour de sa publication au Moniteur belge.

<a name="Art.4" href="#Art.3">Art.</a> 4. Le ministre qui a la Loterie Nationale dans ses attributions est chargé de l'exécution du présent arrêté.
