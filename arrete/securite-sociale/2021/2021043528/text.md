<a name="Art.1er"></a>Article <a href="#Art.2">1er</a>. La cotisation patronale pour financer le Fonds amiante est due, pour l'année 2022, pour le premier, deuxième et troisième trimestre.

<a name="Art.2" href="#Art.1er">Art.</a> 2. Le ministre qui a les Affaires sociales dans ses attributions est chargé de l'exécution du présent arrêté.
