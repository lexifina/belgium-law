<a name="Art.1er"></a>Article <a href="#Art.2">1er</a>. Le présent arrêté est applicable à Bruxelles Environnement.

<a name="Art.2" href="#Art.1er">Art.</a> <a href="#Art.3"> 2</a>. Les divers grades, constituant un même degré de la hiérarchie sont déterminés de la façon suivante :
1° 1er degré: les grades répartis dans les rangs A5 et A4+;
2° 2<sup>e</sup> degré : les grades répartis dans les rangs A4;
3° 3<sup>e</sup> degré : les grades répartis dans les rangs A3;
4° 4<sup>e</sup> degré : les grades répartis dans les rangs A2 et A1;
5° 5<sup>e</sup> degré : les grades répartis dans les rangs B2 et B1;
6° 6<sup>e</sup> degré : les grades répartis dans les rangs C2 et C1;
7° 7<sup>e</sup> degré : les grades répartis dans les rangs D2 et D1.

<a name="Art.3" href="#Art.2">Art.</a> <a href="#Art.4"> 3</a>. L'arrêté du Gouvernement de la Région de Bruxelles-Capitale du 26 septembre 2019 déterminant les grades des agents de Bruxelles Environnement qui constituent un même degré de la hiérarchie, en application de l'article 43 des lois sur l'emploi des langues en matière administrative, coordonnées le 18 juillet 1966, est abrogé.

<a name="Art.4" href="#Art.3">Art.</a> 4. Le Ministre qui a l'Environnement dans ses attributions est chargé de l'exécution du présent arrêté.
