<a name="Art.1er"></a>Article <a href="#Art.2">1er</a>. Pour l'année 2022, le montant du fonds nécessaire pour assurer le financement du coût réel résultant de l'application de prix maximaux pour la fourniture d'électricité aux clients protégés résidentiels est fixé à 14.652.352 euros.

<a name="Art.2" href="#Art.1er">Art.</a> <a href="#Art.3"> 2</a>. Pour l'année 2022, le montant du fonds nécessaire pour assurer le financement du coût réel résultant de l'application de prix maximaux pour la fourniture de gaz naturel aux clients protégés résidentiels est fixé à 71.333.843 euros.

<a name="Art.3" href="#Art.2">Art.</a> 3. Le ministre qui a l'Energie dans ses attributions est chargé de l'exécution du présent arrêté.
