<a name="Art.1er"></a>Article <a href="#Art.2">1er</a>. Un montant de 139.823.101,18 euros est attribué aux autorités visées à l'article 488 du Code judiciaire pour l'indemnisation des prestations accomplies par les avocats, dans le cadre de l'aide juridique de deuxième ligne, durant l'année judiciaire 2021-2022.

<a name="Art.2" href="#Art.1er">Art.</a> <a href="#Art.3"> 2</a>. La valeur d'un point pour l'aide juridique de deuxième ligne est fixée à 90,36 euros pour l'année judiciaire 2021-2022.

<a name="Art.3" href="#Art.2">Art.</a> 3. Le présent arrêté entre en vigueur le jour de sa publication au Moniteur belge.
